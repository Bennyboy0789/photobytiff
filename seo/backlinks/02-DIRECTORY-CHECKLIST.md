# Directory & Citation Checklist

Work top to bottom. **Tier 1 first** (highest impact), then Tier 2, then Tier 3 as time allows. For every listing, copy your details from **01-CITATION-KIT.md** so they're identical everywhere.

**How to use:** Put an `x` in the box as you finish each one. Aim for ~3–5 per sitting; don't try to do all in one day.

Legend: 🔑 = you likely already have this · ⭐ = highest priority · 🆓 = free

---

## TIER 1 — Core citations (do these first — biggest local-SEO impact) 🆓

- [ ] 🔑⭐ **Google Business Profile** — already claimed ✓. Double-check: phone `(910) 779-8088`, website `https://photobytiff.com`, categories, 10+ photos, services + prices all filled in.
- [ ] 🔑 **Facebook Page** — already have ✓. Confirm the "About" uses the NAP + website; add the service area.
- [ ] ⭐ **Bing Places for Business** — https://www.bingplaces.com — you can often import directly from Google. (Powers Bing + some AI search.)
- [ ] ⭐ **Apple Business Connect** — https://businessconnect.apple.com — free; puts you on Apple Maps (huge for iPhone users searching "photographer near me").
- [ ] ⭐ **Yelp for Business** — https://biz.yelp.com — even if you don't love Yelp, the citation matters and it ranks.
- [ ] **Instagram** — already have ✓. Make sure the bio link is `https://photobytiff.com` and location says Spring Lake/Fayetteville.
- [ ] **Nextdoor Business** — https://business.nextdoor.com — hyper-local, great for a Spring Lake service business.

## TIER 2 — Photographer & service directories ⭐ (your niche)

- [ ] **Thumbtack** — https://www.thumbtack.com — you respond to real local leads; also a citation. High ROI for bookings.
- [ ] **Bark** — https://www.bark.com — lead-gen + citation.
- [ ] **The Bash** (formerly GigMasters) — https://www.thebash.com — party/event photographers (cake smash, birthdays).
- [ ] **WeddingWire** — https://www.weddingwire.com — if you do ANY couples/maternity/engagement work; strong DA. (Cross-lists to The Knot.)
- [ ] **The Knot** — https://www.theknot.com — same as above; often one signup covers both.
- [ ] **Fash / other photographer marketplaces** — optional, lower priority.

## TIER 3 — General business directories 🆓 (NAP consistency signals)

- [ ] **Yellow Pages** — https://www.yellowpages.com
- [ ] **Manta** — https://www.manta.com (small-business focused, lets you specify region)
- [ ] **Better Business Bureau** — https://www.bbb.org (free basic listing; trust signal)
- [ ] **Foursquare / Places** — https://foursquare.com
- [ ] **Angi** (formerly Angie's List) — https://www.angi.com
- [ ] **Hotfrog** — https://www.hotfrog.com
- [ ] **Chamber of Commerce** — join the [Spring Lake](https://www.springlakenc.gov) or [Greater Fayetteville](https://www.faybiz.com) Chamber (small fee, but a real local backlink + networking)

## TIER 4 — Local & military community (highest-value links — see outreach templates)

These usually need a short email or form (use **03-OUTREACH-TEMPLATES.md**), not just a signup:

- [ ] **Macaroni KID Fayetteville–Hope Mills–Fort Bragg** — https://fayettevillenc.macaronikid.com — local family events/resource site; ask about a business listing or sponsored feature.
- [ ] **DistiNCtly Fayetteville** — https://www.distinctlyfayettevillenc.com — the official visitors bureau; see if photographers can be listed under local services/vendors.
- [ ] **Cumberland County family/moms directory** — https://ccpfc.org/business-directory — community family resource directory.
- [ ] **Local wedding/event venues** (preferred-vendor lists) — Vizcaya Villa, SkyView on Hay, Key Rose Estate, Cape Fear Botanical Garden, Villa Mirabela. Email each about being added as a recommended photographer (template provided).
- [ ] **Fort Bragg spouse & family Facebook groups** — join and become a known, recommended photographer (referrals + occasional links). Search: "Fort Bragg spouses," "Fayetteville moms," "Spring Lake community."
- [ ] **Local vendors you work with** — cake makers, boutiques, event planners, daycares, birthing classes, doulas. Ask for a mutual "preferred vendor" link (template provided).
- [ ] **North Carolina mom blogs** — see the [Feedspot NC mom blogs list](https://bloggers.feedspot.com/north_carolina_mom_blogs/); pitch a guest post or "featured local photographer" (template provided).

## ⚠️ Avoid these (they waste money or hurt you)
- ❌ "Get 500 backlinks for $20" services / Fiverr link gigs — spam, can trigger penalties.
- ❌ Auto-submission tools that mass-blast directories with slightly-different info — inconsistency hurts more than the links help.
- ❌ Paying for "guest posts" on unrelated random blogs.
- ✅ The rule: a link is only worth getting if a real person/organization would plausibly choose to list you. Everything on this checklist passes that test.
